# betcerto-site — redirecionamento

Este repositório existe apenas para **redirecionar a URL antiga** do site.

O projeto foi renomeado para **BetStatistics** e vive em:
👉 https://augustocbb.github.io/betstatistics-site/

Repositório atual: https://github.com/augustocbb/betstatistics-site

> O GitHub Pages não emite 301 (redirect de servidor). Aqui usamos `<meta refresh>` +
> `rel=canonical` + JS, que é o máximo possível num host estático. O `404.html` preserva
> o caminho, então links profundos (ex.: `/calculadora.html`) caem na página equivalente.
